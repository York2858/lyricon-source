# 翻译数据库查看与管理

入口：**AI 实验室 → AI 歌词翻译 → 翻译数据库**。

- 按歌名和歌手归类，同一首歌的不同语言、模型、风格生成的翻译进入版本列表。
- 搜索歌名、歌手、原文和译文；支持目标语言筛选、只看收藏、最近保存、最早保存和歌名排序。语言与排序菜单从按钮下方展开。
- 显示翻译条数、译文句数和收藏数量；列表分页加载。
- 双语对照、只看译文、只看原文；整首歌词内搜索、逐句复制、文本选择、字号调整、回到开头和跳到末尾。
- 按翻译版本收藏，复制完整双语歌词，使用系统文件选择器导出 UTF-8 TXT、逐行 LRC、逐字 LRC、增强逐字 LRC 或 TTML，或打开系统分享面板。
- 导出可选双语、仅原文、仅译文。歌词行使用紧凑排版，复制图标位于侧边。
- 删除当前版本、整首歌，或者批量选择歌曲（每次最多 100 首）。确认框列出影响记录数和收藏数。

## 旧数据兼容

数据库通过增加字段保留旧译文和原有时间，版本 3 新增原始逐行、逐字时间轴。
旧缓存只有内容哈希、译文和时间，无法凭空恢复歌名、歌手、原文、语言或模型；页面会显示“旧记录”与“未记录”。
再次播放且命中旧缓存时，会补齐歌曲信息、原文、目标语言、模型及播放器提供的时间轴，不发起新的翻译请求。已有收藏和生成时间保留。
未知歌曲的旧记录按缓存 ID 分开，避免错误合并。

## 歌词导出

逐行 LRC 使用 `[mm:ss.SSS]`；逐字 LRC 在各词前使用方括号时间；增强逐字 LRC 使用行首方括号和词前尖括号时间。
TTML 使用标准 TTML 命名空间，原文可含带 begin/end 的逐字 span，双语译文以 `ttm:role="x-translation"` 附于对应原句。
格式遵循 Lyrico 的上述时间标记方式，不依赖或改动 Lyrico 工程。

时间来自原始播放器歌词，不按字数猜测。缺少原文逐字时间的行按逐行导出，AI 译文使用对应原句的行时间。
缺少完整逐行时间的旧记录可以导出 TXT；播放补齐后可导出同步歌词。文件扩展名分别为 `.txt`、`.lrc`、`.ttml`。
所有导出方式（包括“另存为”）优先使用实际音乐文件的基础名，例如音乐为 `02. WINDY SUMMER.m4a`，歌词为 `02. WINDY SUMMER.lrc`。
保留音频基础名的序号、空格、大小写和标点，只替换扩展名；确定导出文件名之前等待正在进行的音乐查找完成。
未定位到音频文件时，使用 Lyrico 默认的“歌手 - 歌名”规则；缺少歌手时只用歌名，信息均为空时用 `lyrics`。

导出时默认使用“音乐所在文件夹”。通过播放器媒体会话和系统媒体库自动定位本地音乐，显示实际目录，首次授权窗口直接定位到该目录。
已授权过包含该目录的上级文件夹时，可直接保存到音乐实际所在的子文件夹。
首次缺少权限时需在系统文件夹选择器中确认授权读写，
之后按歌曲记住目录，不同翻译版本共用该歌曲目录。可随时更换目录，或切换“另存为”使用系统文件保存窗口。
历史记录也会尝试按歌名、歌手精确匹配媒体库；当前歌曲同时校验播放器的专辑与时长信息。
找到多个匹配文件、播放明确的在线音源、私有缓存文件、未被媒体库收录等情况提供手动选择，避免保存到错误的同名歌曲目录。
仅使用系统授予的文件夹权限，不申请整个存储空间的管理权限。
目录授权失效时会重新请求选择；同名文件提供取消、另存一份或覆盖，覆盖前不会写入原文件。

### ColorOS 17 文件夹授权

优先调用设备自带的标准 Android DocumentsUI，避免 ColorOS 文件管理器忽略起始目录。
传入的是音乐目录的 document URI；授权完成后检查真实的持久读写权限，不再忽略授权错误。
失败时保留待导出内容，支持“系统窗口重试”和“其他选择器”。
系统可能禁止内部存储根目录、Download 根目录、Android/data 等受限目录；按钮灰色时请进入
Music 或具体歌曲子文件夹后授权。在一加 13 的 ColorOS 17 上，已确认 Music 可获得持久读写授权。
也可以使用单文件“另存为”或批量 ZIP，二者不依赖目录授权。

### 批量导出

在歌曲列表点击“批量管理”，勾选歌曲或“全选结果”，然后点击“批量导出”。
全选按当前搜索、语言和收藏筛选分页读取，每批最多 100 首。每首导出最新的翻译版本。
支持五种格式、双语/原文/译文，以及分别保存到音乐目录、统一文件夹、打包 ZIP 三种方式。
默认跳过同名文件，可选另存一份或覆盖。统一目录内两首歌曲重名时，即使选择覆盖，也会为本批次后来的歌曲另存一份，避免相互覆盖。
ZIP 内按歌曲分类，保留音频基础名，并附带导出报告；未匹配到音频时使用“歌手 - 歌名”。
导出逐首处理，可在当前歌曲完成后停止，保留已完成文件和有效 ZIP。
缺少时间轴、缺少原文、无本地目录或无目录授权等问题单独列出，其余歌曲继续导出。
结果页显示成功、跳过、失败和未处理数量，并可复制逐首结果。

## 模块更新

数据库由 SystemUI 进程持有。本次新增了数据库访问端点，更新 APK 后，
需要重启系统界面或手机，让新模块代码载入。未连接时展示明确原因和重试入口，保留已加载内容。
读取、收藏、导出与删除均不会主动调用 AI；删除后，日后再次播放可能重新翻译。

## 实现边界

广播路由只发现 Messenger 端点；每次实际读取和管理操作，都根据系统写入的 `Message.sendingUid`
校验请求来自本应用。回复同样校验 SystemUI 身份。
歌曲、版本和歌词分页传输，单页歌词按约 180 KB 限制，避免超出 Binder 事务大小。
数据库查询和变更在 IO 协程中执行，并与翻译缓存共用互斥锁。
删除同步清理内存缓存和推进代次，晚到的旧翻译任务无法将已删除记录重新写回。
不保存 API Key 或服务地址。
